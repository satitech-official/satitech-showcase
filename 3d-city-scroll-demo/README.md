# Citywise 3D Scroll Concept

A fresh capability demo created by Sati Technologies for a city-wise landing-page brief.

## Interaction

- Procedural Three.js/WebGL city environment
- GSAP ScrollTrigger camera choreography
- District-by-district narrative transitions
- Pointer-responsive depth and ambient lighting
- Responsive layout and graceful fallback

Live demo: https://satitech-official.github.io/satitech-showcase/3d-city-scroll-demo/
